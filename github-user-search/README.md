# GitHub User Search

A React application built with Vite that allows users to search for GitHub users and view their profiles.

## Features

- Search for GitHub users by username
- Filter by location and minimum number of repositories
- View user profiles with detailed information
- Responsive design with Tailwind CSS

## Technologies

- React 19
- Vite
- Tailwind CSS
- Axios
- GitHub API

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Project Structure

- `src/components/` - React components
- `src/services/` - API services
- `src/App.jsx` - Main application component
